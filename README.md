# Quadri Elettrici

App web per comporre quadri elettrici su guida DIN: libreria componenti (con importazione da Excel/CSV), schema unifilare, calcolo cavi e distinta materiali.

**Apri l'app:** https://desideri75.github.io/quadri-elettrici/

- Salvataggio automatico sul dispositivo a ogni modifica e alla chiusura.
- Salvataggio in cloud facoltativo in un Gist privato del proprio account GitHub (Progetti → ☁ Cloud).
- Esportazione e importazione in ZIP (singolo quadro o backup completo).
- Funziona anche offline e si può installare sul telefono come app.

I calcoli sono semplificati e indicativi: il progetto va verificato da un tecnico abilitato secondo CEI 64-8.
